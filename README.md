# EU3DT3DS
The 3DS version of Terraria has no 3D capability, So someone made a mod that you put on your SD card and it gives you that 3D capability back. Issue is that mod is for the USA version of Terraria only, This one is for the EU version. I did not convert it or build it myself, Claude did. The user who made the USA version is: <a href="https://github.io/mattvideoproductions"</a>.
